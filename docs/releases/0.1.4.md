This release refreshes the interface and adopts a tray-popup workflow.

## New interface

- Graphite surfaces, Segoe UI when available and a muted blue-gray accent replace the green styling, including the tray icon.
- Click the tray icon to open a compact **368 × 304** quick panel with volume, Night/Headphones/Speakers, leveling and Start/Stop. Click again, outside the panel, or press Esc to dismiss it; processing continues.
- **Settings** is now a separate window containing Audio, optional Driver and Updates. Its height follows the current page. Closing it keeps Sound Lock in the tray.
- Popup and dialog borders/shadows make their edges visible. Detail dialogs dim and block their background.
- Placement accounts for taskbar edges, monitor work areas and DPI. Neither the popup nor Settings needs scrolling.

## Improved updates

- **Settings > Updates > Check for updates** shows the installed version and checks this repository without login.
- Startup checks run in the background by default. **Check for updates on startup** saves your opt-out; available updates appear in the quick panel and tray menu/tooltip, without intrusive no-update or network-error dialogs.
- **Download and install** shows progress, verifies the download, preserves settings, restores/stops audio and restarts the app. **Install later** defers the restart; **Restart & install** finishes a prepared download. Errors remain visible and the previous version is retained for startup rollback.
- The updater prefers canonical executable names, supports architecture-specific x64 names when a release has multiple variants, and still reads historical release metadata.

## Required manual upgrade

**Download 0.1.4 manually when upgrading from 0.1.3 or earlier.** The standalone asset is now **SoundLock-v0.1.4.exe**, and the 0.1.3 updater accepts only the old filename pattern. No legacy alias is included. Close the old version through Quit before replacing it. Your settings are kept in the existing AppData location.

The Windows x64 ZIP contains `sound-lock.exe`, README and the MIT license. A standalone `SoundLock-v0.1.4.exe` and SHA256SUMS are also attached. Future compatible releases can be installed directly through 0.1.4's Updates page. Processing remains stopped after restart; start it again when ready. No driver is installed by this release.

## Validation

53 standard tests pass. Native preview runs exercised real tray callbacks, popup toggling, focus loss, separate Settings, minimize/restore, hidden commands and Quit. The published 0.1.3 updater was also tested launching the new 0.1.4 GUI with an isolated preview receipt: the popup rendered, acknowledged startup and cleaned the old helper/backup. These checks used fake endpoints and no user settings writes.

The UI framework was updated to egui/eframe 0.37 for hidden-window logic support; source builds now require Rust 1.95+. Windows CI checks all feature builds and runs the existing native updater replacement/rollback fixtures. Live VB-CABLE playback, physical mixed-DPI monitor switching and an update during real audio playback remain manual checks. The executable is unsigned.
