Sound Lock is a standalone Windows 10/11 x64 tray app for steadier movie audio. This is an early portable release.

## Included

- Driver-free **System limiter** reduces peaks through Windows volume controls.
- **Boost + leveling** provides gated leveling, compression, up to 400% amplitude gain (+12.04 dB), and a look-ahead sample-peak limiter with Night, Headphones and Speakers profiles.
- Optional in-app VB-CABLE download, checksum/signature verification and a separate interactive installation step. The third-party driver is not bundled.
- **Auto-route browser** switches Chrome, Edge, Firefox, Brave, Opera or Vivaldi to the selected Source during processing and restores its previous output on Stop/Quit. New browser audio processes are tracked, with rollback and durable recovery.
- Compact English-only interface, dimmed modal dialogs and working tray window restoration.

## Download and run

Download the Windows x64 ZIP, extract it and run `sound-lock.exe`. The ZIP includes README and the MIT license. A standalone EXE and `SHA256SUMS.txt` are also attached. Rust is not needed; there is no application installer or autostart. The executable is unsigned.

For VB-CABLE, install the optional driver and restart Windows. Select **Boost + leveling > Setup > Audio**, use **CABLE Input** as Source and real headphones/speakers as Listening device. Enable **Auto-route browser**, choose the browser, start processing and play audio. Keep the physical listening device as the Windows default. Start at 100% and adjust the boost as needed. See README for the complete setup and driver licensing.

## Validation and limits

35 automated tests and Windows formatting/lint/build checks pass. A separate native Windows test changed and restored only its own audio preferences. Full live browser-to-VB-CABLE playback, long listening sessions and device reconnection behavior have not yet been verified on the development machine.

Full leveling/boost requires VB-CABLE or another inaudible playback source separate from the listening device. System limiter cannot boost above the current device maximum. Processing raises quiet material generally; it does not isolate dialogue. No surround/passthrough or true-peak processing is provided.

If the browser has closed, output recovery waits for a registered browser audio session while Sound Lock is open. After a crash or force kill, relaunch Sound Lock and play browser audio for recovery; no watchdog remains after Quit. Automatic routing uses an internal Windows interface and may need updates for future Windows versions. Manual Windows mixer routing remains available.
