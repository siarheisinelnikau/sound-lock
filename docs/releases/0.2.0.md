Sound Lock 0.2.0 adds six interface languages and an immediate light/dark theme switch while preserving your audio settings.

## Added

- Choose English, Russian, French, German, Spanish or Italian in Settings. The popup, profiles, audio setup, optional driver setup, update controls, status messages and tray menus use the selected language immediately.
- Switch between coherent Light and Dark themes directly above the Settings tabs. The popup, controls, selections, native window appearance and detail dialogs follow the choice.
- Language and theme preferences survive restart. Existing settings retain all audio and update preferences, starting in English with the original dark theme.

## Improved

- Settings has room for longer translated labels and help. Application-owned status messages are translated; device names, browser names and detailed external diagnostics stay intact.
- Since v0.1.4, the app uses a reactive CPU rasterizer with Windows GDI presentation. Static and hidden windows retain their rendered content instead of continuously rebuilding it. The popup uses its own per-pixel border and shadow without a second native frame.
- Updates use the shared Rust updater while retaining startup opt-out, explicit download/install, settings preservation and restart/rollback handling.

## Download and upgrade

Windows 10/11 x64: use `SoundLock-v0.2.0.exe`, or extract `sound-lock-0.2.0-windows-x64.zip` and run `sound-lock.exe`. `SHA256SUMS.txt` covers both assets. The executable is unsigned. No driver is installed automatically.

Versions 0.1.4 and newer can discover the canonical EXE in Settings > Updates. If upgrading from 0.1.3 or earlier, quit the old application and download this version manually once because those clients recognize only the historical filename. Your settings remain in the existing AppData location.

## Verification

Automated checks cover catalog completeness and parameters, settings migration and persistence, all translated settings pages in both themes, existing audio/DSP behavior and updater fixtures. Real audio playback, vendor driver installation, physical mixed-DPI behavior and an in-place update of a live installation remain manual checks; no user audio routes or settings were changed during this work.
